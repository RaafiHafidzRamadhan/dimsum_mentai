## 🚀 Cara Menjalankan Website

1. Buka folder `website_dimsum`.
2. Klik dua kali (double click) pada file `index.html`.
3. Website akan langsung terbuka di browser (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox, dll.) tanpa perlu install apapun.
4. Tampilan sudah **100% responsif**, rapi di layar HP (smartphone), tablet, maupun laptop/komputer desktop.

## 📷 Cara Mengganti Foto di Masa Depan

Jika ingin mengganti foto menu atau foto logo di kemudian hari:
1. Cukup masukkan file foto baru ke dalam folder `assets/images/`.
2. Berikan nama yang sama persis:
   - Ganti logo: simpan dengan nama `logo-mentaiku.png`
   - Ganti foto Dimsum Mentai: simpan dengan nama `dimsum-mentai.jpg`
   - Ganti foto Dimsum Chili Oil: simpan dengan nama `dimsum-chili-oil.jpg`
   - Ganti foto Mix Dimsum: simpan dengan nama `dimsum-mix.jpg`
   - Ganti brosur/flyer: simpan dengan nama `flyer-mentaiku.jpg`
3. Setelah diganti, refresh halaman di browser (`F5` atau `Ctrl + R`), maka foto otomatis berubah tanpa perlu edit kode HTML!
